# The Tell — Beatrix

A static, GitHub Pages-ready landing page for Beatrix's private Tell recording.

## Publish on GitHub Pages

1. Upload every file in this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The page has no build step or external code dependencies. Keep the filenames unchanged so the artwork, favicon, and audio continue to load.

## Included files

- `index.html` — landing page and custom audio player
- `hero-video.mp4` — continuously looping hero video
- `beatrix-the-tell.m4a` — Beatrix's recording (about 20:52)
- `og.png` — social share image used for link previews
- `favicon.png` — browser icon
- `.nojekyll` — tells GitHub Pages to serve the folder as-is
